Developer: NXC MAHIM

## Overview
A secure, anti-ban protected FastAPI backend service for fetching real-time Free Fire player information.

## Deployment Guide
1. Push all project files to a GitHub repository.
2. Connect the repository to Render or Railway.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
